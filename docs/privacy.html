Privacy Policy

RStartpage · Last updated 2026-09-15

Data accessed

RStartpage accesses Chrome bookmarks to provide its bookmark workspace and uses Chrome extension storage for preferences and presentation metadata. Session Manager reads tab titles and URLs when the user explicitly saves or updates a session. Link Checker makes user-initiated requests to selected bookmark URLs. Proxy features access Chrome proxy settings and proxy authentication events to apply user-configured profiles and routing rules.

Data collection and transmission

RStartpage does not operate a developer-controlled backend and does not transmit bookmark data, sessions, settings, proxy profiles, browsing data or credentials to the developer, analytics services, advertising systems or trackers.

Network activity occurs only when required for user-facing features. Link Checker connects to destinations selected by the user. Proxy mode routes browser traffic through proxy servers configured by the user. Chrome/Google may synchronize bookmarks and extension storage when Chrome Sync is enabled.

Credentials

Proxy passwords are stored locally by default. Users may explicitly choose to synchronize a password or include passwords in a JSON export.

Sharing

RStartpage does not sell, rent or share user data for advertising, profiling or unrelated purposes.

Retention and deletion

Bookmarks remain in Chrome Bookmarks until the user removes them. RStartpage preferences remain in Chrome extension storage until changed or reset. Uninstalling the extension does not intentionally delete the user's RStartpage bookmark folder.

Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.
