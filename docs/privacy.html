Privacy Policy

RStartpage · Last updated 2026-09-24

Data accessed

RStartpage accesses Chrome bookmarks to provide its bookmark workspace and uses Chrome extension storage for notes, saved sessions, preferences and presentation metadata. Session Manager reads tab titles, URLs, order and pinned state when you explicitly save or update a session.

When you explicitly create a note from the toolbar popup, a bookmark, a page or selected page text, RStartpage stores the title, source URL, selected text and other content you choose to save. Link Checker makes user-initiated requests to selected bookmark URLs. Proxy features access Chrome proxy settings and authentication events to apply profiles and routing rules you configure.

Data collection and transmission

RStartpage does not operate a developer-controlled backend and does not transmit bookmark data, notes, sessions, settings, proxy profiles, browsing data or credentials to the developer, analytics services, advertising systems or trackers.

Network activity occurs only for features you use. Link Checker connects to destinations you select. Proxy mode routes browser traffic through proxy servers you configure. Chrome/Google may synchronize bookmarks, supported settings, proxy profile definitions and notes you explicitly select when Chrome Sync is enabled.

The current Chrome Web Store build does not request Google Drive access. If cloud backup is introduced in a future store version, the privacy disclosures and requested permissions will be updated before that version is published.

Credentials and archives

Proxy passwords stay local by default. You may explicitly synchronize a password or include passwords in a local archive. RStartpage archives are not encrypted.

Sharing

RStartpage does not sell, rent or share user data for advertising, profiling or unrelated purposes.

Retention and deletion

Bookmarks remain in Chrome Bookmarks until you remove them. Notes, sessions, preferences and metadata remain in Chrome extension storage until changed, reset or removed. Uninstalling the extension does not intentionally delete your bookmark folder.

Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.
