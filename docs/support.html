Support

Help, bug reports and feature feedback for RStartpage.

Before reporting a problem

Confirm that Chrome is up to date, reload RStartpage from chrome://extensions, and check whether the issue is still reproducible. For data-related problems, avoid deleting extension storage before making a backup if the interface is still accessible.

Report a bug or request a feature

Use the public GitHub Issues page and include the RStartpage version, Chrome version, the affected module, clear reproduction steps and screenshots that do not contain private data.

Open GitHub Issues →

Privacy and sensitive data

Do not post proxy passwords, private hostnames, internal IP addresses, authentication tokens, private bookmarks or personal session URLs in public issues.
