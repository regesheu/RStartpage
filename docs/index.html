Bookmarks, notes and browser tools in one start page.

RStartpage turns Chrome's New Tab into a customizable workspace built around your existing bookmarks, with notes, saved sessions, link maintenance, portable backups and optional proxy routing.

Download latest View releases

Free to install from GitHub. No account, ads, analytics or developer-operated backend.

Current capabilities

Your everyday browser workspace, kept in one place.

01

Bookmark workspace

Organize normal Chrome Bookmarks into sections, groups and rich cards with search, descriptions, colors, icons, sizes and drag & drop.

02

Global Quick Access

Pin important bookmarks from any section into one shared block, so the links you use most stay together.

03

Notes

Create notes from selected text, the current tab or a bookmark. Use groups, tags and search, and choose individual notes for Chrome Sync.

04

Sessions

Save windows with tab order and pinned state, then restore them in a new window, add them here or replace the current window.

05

Link maintenance

Find duplicate URLs, edit results inline and check links for HTTP errors, timeouts and unavailable destinations.

06

Proxy profiles

Switch between HTTP, HTTPS, SOCKS4 and SOCKS5 profiles with optional authentication, bypass masks and latency tests.

07

Smart routing

Route matching domains, IPs or URL patterns through DIRECT or a selected profile using ordered Smart Proxy Rules.

08

Data archives

Export selected sections to ZIP, preview an import, then merge or replace links, notes, proxies, sessions, settings and wallpaper.

09

Google Drive backups

In OAuth-configured builds, create, list, download, restore and delete complete backups in the extension's private Drive data.

Install

Install from GitHub in a few minutes.

  1. DownloadDownload RStartpage-latest.zip from the latest GitHub Release.
  2. ExtractUnzip it to a permanent folder. Chrome needs that folder to remain on disk, and future updates should use the same location.
  3. Open extensionsOpen chrome://extensions and enable Developer mode.
  4. Load RStartpageClick Load unpacked and select the extracted folder containing manifest.json.
  5. Optional: pin itPin RStartpage from Chrome's Extensions menu for quick session and proxy controls.

Privacy

Local-first by design.

RStartpage does not operate its own account system, analytics service or backend. Bookmarks remain Chrome Bookmarks; notes and sessions stay local by default. Data reaches Chrome Sync, a local archive, Google Drive or your chosen proxy only when you enable the corresponding feature.
