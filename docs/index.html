Chrome New Tab · Local-first

Your bookmarks, sessions and proxy tools in one start page.

RStartpage replaces Chrome's New Tab with a customizable workspace built around your existing Chrome Bookmarks. It also includes saved sessions, bookmark diagnostics, optional proxy profiles and Smart Proxy Rules.

Download latest View releases

Free to install from GitHub. No account, ads, analytics or developer-operated backend.

What it does

A start page that stays close to Chrome.

01

Bookmarks

Organize normal Chrome Bookmarks into sections, groups and rich cards with search, descriptions, colors, icons and drag & drop.

02

Sessions

Save the current browser window and restore a set of tabs later from the toolbar popup or Session Manager.

03

Diagnostics

Find duplicate bookmarks and check links inline without leaving the start page.

04

Proxy profiles

Switch between user-configured HTTP, HTTPS and SOCKS profiles, with optional authentication, bypass masks and health checks.

05

Smart routing

Route matching domains or IP masks through a selected proxy profile or DIRECT using ordered Smart Proxy Rules.

06

Backup & sync

Use Chrome Sync for supported settings and export/import RStartpage data as JSON when you want a portable backup.

Install

Install from GitHub in a few minutes.

  1. DownloadDownload RStartpage-latest.zip from the latest GitHub Release.
  2. ExtractUnzip it to a permanent folder. Keep using that same folder for future updates.
  3. Open extensionsOpen chrome://extensions and enable Developer mode.
  4. Load RStartpageClick Load unpacked and select the extracted folder containing manifest.json.
  5. Optional: pin itPin RStartpage from Chrome's Extensions menu for quick session and proxy controls.

Privacy

Local-first by design.

RStartpage does not operate its own account system, analytics service or backend. Bookmarks remain Chrome Bookmarks. Proxy passwords stay local unless you explicitly enable password sync for a profile.
