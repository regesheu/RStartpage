RStartpage

A customizable Chrome New Tab workspace for bookmarks, saved sessions, bookmark diagnostics and optional user-configured proxy routing.

Local-first

RStartpage has no developer-operated backend, advertising or analytics. Bookmarks remain Chrome Bookmarks and supported settings can sync through Chrome's own synchronization features.

Features

  • Sections, groups and searchable bookmark cards
  • Session Manager, Duplicate Finder and Link Checker
  • Custom backgrounds, themes, colors and icons
  • Optional proxy profiles, quick switching and Smart Proxy Rules
  • JSON backup and restore
