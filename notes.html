Помощь по заметкам

Локальное хранение. Новые заметки по умолчанию сохраняются только на этом устройстве.

Синхронизация. Включите переключатель внутри заметки, чтобы отправить её на другие устройства Chrome. Лимит заметок для синхронизации — 70 КБ.

Группы и теги. Группа задаёт раздел, а теги помогают быстро фильтровать заметки.

Создание из браузера. Выделите текст на странице, откройте контекстное меню и выберите «Создать заметку из выделения».

Источник. При создании из страницы ссылка сохраняется в заметке автоматически.
