Notes help

Local storage. Without Google Drive, notes stay on this device.

Google Drive. Connect it in Settings → Data below export and import. Cloud backups can be created, downloaded, restored and deleted.

Chrome Sync. Until Drive is connected, enable sync only for the notes you need. At 70% of the quota, RStartpage suggests connecting Drive.

Groups and tags. A group organizes notes; group buttons show counts and tags filter the list.

Import and export. The arrow button opens Settings → Data. Select Notes for a separate ZIP archive or save every section together.
