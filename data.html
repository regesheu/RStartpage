Import & export

Move RStartpage between computers, import generic JSON, or copy an existing Chrome Bookmarks folder.

Заметки

Отдельный экспорт и импорт заметок без изменения закладок.

Export RStartpage

Saves sections, groups, links, descriptions, pins, card sizes, section/group colors and icons, and interface settings.

The export contains only RStartpage data. Other Chrome bookmarks are not included.

Import JSON

Supports RStartpage backups and the generic JSON structure below.

Mode

Import from Chrome Bookmarks

Choose an existing folder. RStartpage copies its contents and does not remove the original bookmarks.

The selected folder becomes a section. Nested folders become groups; deeper nesting is represented with “ / ” in the group name.

Minimum generic JSON structure

If you generate JSON yourself, sections use the technical key workspaces, followed by groups and bookmarks.

{
  "workspaces": [
    {
      "title": "Work",
      "color": "green",
      "icon": "work",
      "groups": [
        {
          "title": "Development",
          "description": "Developer tools and dashboards",
          "color": "blue",
          "icon": "code",
          "bookmarks": [
            {
              "title": "GitHub",
              "url": "https://github.com",
              "description": "Repositories and pull requests",
              "pinned": true,
              "size": "wide"
            }
          ]
        }
      ]
    }
  ]
}
Required

workspaces[], groups[], bookmarks[], plus title and url for every link.

Optional

Sections and groups may have color and icon; groups and links may have description; links may also have pinned and size.

color: none / green / blue / purple / orange / red / graphite. icon: any built-in icon name such as none, folder, grid, bookmark, briefcase, code, server, database, globe, music, shopping and many others. size: small / normal / wide.

Reset RStartpage

Deletes only RStartpage data and visual metadata. Other Chrome Bookmarks are not affected.
